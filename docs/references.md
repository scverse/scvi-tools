# Bibliography

## Citing scvi-tools

If you use scvi-tools in your work, please cite {cite:p}`Gayoso22`, along with the
publication of each model you use (see the corresponding user guide page).

scvi-tools is part of the scverse ecosystem {cite:p}`Virshup24` and interoperates with
scanpy {cite:p}`Wolf18` and anndata {cite:p}`Virshup24-2`.
It is built on PyTorch {cite:p}`Paszke19` and PyTorch Lightning {cite:p}`Falcon19`.
